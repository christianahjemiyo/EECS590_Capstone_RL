# V3

`V3/` contains the world-model extension of the capstone.

## Contents

- `scripts/`: Version 3 runners and figure-generation utilities.
- `src/`: V3-contained package code, including the world-model module.
- `docs/`: V3 design notes, model card, and instructor-facing summary.
- `tests/`: V3-specific tests.
- `outputs/V3/`: committed Version 3 artifacts.

## Dependencies

V3 uses the shared root dataset under `../data/` and the V2 benchmark artifacts under `../V2/outputs/v2_outputs/`.
