# EECS590 Capstone -- Versioned Repository Layout

This repository is organized by version at the top level:

- `V1/`: original scaffold, baseline code, baseline scripts, and baseline outputs.
- `V2/`: expanded benchmark workflow, V2 pipeline assets, and V2 outputs.
- `V3/`: world-model extension, V3 docs, V3 scripts, V3 tests, and V3 outputs.
- `data/`: shared canonical datasets used across versions.

## Start Here

1. `V1/README.md`
2. `V2/README.md`
3. `V3/README.md`

## Structure

`data/` remains shared at the repository root so the repository does not duplicate large datasets across all three versions. Version-specific code, docs, tests, and outputs now live under their matching version directory.
